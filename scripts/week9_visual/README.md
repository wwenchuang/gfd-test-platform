# 已发布 UI 基线的视觉定位对照

同事在真实的功夫豆测试工作台操作用例库、选择清单和开始测试页面。五项操作是勾选后移除、刷新保留版本、进入开始测试、移除最后一条用例、目录翻页后返回。两种执行方式共用第六周的页面准备、后台 GET 响应和业务断言。场景需要可执行的已发布用例，分页还需要同一应用下超过 20 条记录。

AI 组使用 Midscene SDK 的 `aiLocate` 读取截图，返回定位中心，再在命中原目标时由 Playwright 点击该点。基准组按 DOM 定位器操作。两组都以相同步骤选定应用、把目标滚入可见视口，再检查真实 DOM、接口返回的版本和清单状态。定位器只作预备滚动和点击前保护，AI 给错坐标会记入失败。本实验衡量在给定任务和可见目标下的视觉定位及连续点击；未测自由规划、滚动搜索或手机发版执行。

## 服务端试跑

使用可访问工作台本机 `127.0.0.1:8088` 的隔离目录与非特权账号。保留源码相对路径，至少需要本目录和 `task_server/fixtures/week5_web/{workflows,policy,proxy}.js`。运行器按锁文件使用 Midscene 1.10.7、Playwright 1.55.1、Chromium headless shell 1193。生产 Runner 不需要安装或升级依赖。

```sh
cd scripts/week9_visual
npm ci --ignore-scripts --legacy-peer-deps --no-audit --no-fund
node --test runner.test.js
```

通过环境提供与第六周相同的 `PLAYWRIGHT_BROWSERS_PATH` 和 `LD_LIBRARY_PATH`。将管理员已授权的当前会话以及同一身份的 userId、服务端百炼配置由受限进程通过匿名标准输入管道传给 Node。标准输入只接收对象 `{"token":"…","userId":"…","model_key":"…","model":"…","base_url":"…"}`。不要保存此输入或将秘密作为命令行参数。模型和地域跟随本机配置，SDK 固定使用 qwen3 家族。节点只允许向指定地域的百炼兼容接口发起视觉请求。

```sh
# 以下命令均需从上述管道读取输入。第二个参数为本次最多新执行的试次。
node run.js /var/tmp/visual-run-results 2
node run.js /var/tmp/visual-run-results 100
# 仅继续确定性对照
node run.js /var/tmp/visual-run-results 100 control
```

打开一次新的浏览器上下文执行每个试次。业务访问仅经上一版封闭策略的回环 GET，浏览器只见脱敏资料与占位凭证，WebSocket 被关闭。两组每项各十轮，奇偶轮对换先后。模型每个步骤最多一次、每组场景最多三次、整批最多 110 次，一次最多输出 512 tokens，35 秒请求超时。成本留存模型用量回执，缺失时显示未知，按量费用以账单为准。模型网络或权限阻塞应和定位失败、业务断言失败分开查看。

每次操作同步保存 `w9-report.json`，包含状态、调用、已知 tokens、耗时和证据。前后截图存入同目录 `visual-artifacts/<sha256>.png`。发布时使用工作台受权取图入口。运行中断时，已占用试次记为中断并保留，下一次继续后续试次。脚本、浏览器、模型、身份及每个场景首屏的静态资源和基线版本会被冻结。条件变化需要新输出目录。同一个目录只能有一个进程，若硬终止留下 `.run-lock`，先确认文件中的 PID 已退出，再手动移除锁。

结论解读时应同时查看尝试数、通过数和阻塞原因。AI 误点拦截与业务断言失败都保留第一手记录；确定性流程适合稳定控件，高变动布局才值得结合具体的视觉定位成功率、成本与时延选取 AI 步骤。PNG 和逐次回执须经工作台权限访问。

## 单独复验目录搜索与异常保护

当真实分组只有一页，分页会保留 `no_second_page` 原始记录。可以另开一个独立批次，执行现有目录搜索。两组都选同一应用，以真实已发布用例名进行填写、回车查询和清空。AI 组还要从截图识别并正确点击搜索框。提交和清空均核对后端返回的实际 ID 顺序；查询额外核对资产版本，清空额外核对原目录恢复。每轮保存填写前、已输入、查询后和清空后的页面。补批同样使用受限匿名管道输入，最多再发 10 次模型请求。

```sh
node search-run.js /var/tmp/visual-search-results 2
node search-run.js /var/tmp/visual-search-results 20
node fault-check.js /var/tmp/visual-controls.json
```

最后一条命令使用锁定的浏览器和真实 SDK，模拟模型拒绝授权与 35 秒无响应，核实单步、单场、整批预算以及域名和写入保护。它无需凭证，外部模型调用数为零。报告中故障样本另计，和业务成绩分开归档。生产 YAML、Top3 基线和 Runner 门禁沿用既有版本；此次 JS 对照不会写入 YAML 或发布脚本。
