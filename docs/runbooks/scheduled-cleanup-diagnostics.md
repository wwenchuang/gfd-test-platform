# 定时清理命中项只读诊断

输入是同目录 `scheduled_cleanup_scope.py` 生成的只读范围报告。本工具只读取其中 `earlier_output=true` 且结构可判定的版本，范围沿用原报告，不重新解析当前定时成员；报告生成后定时配置可能已变化。

每条记录输出定时任务 UUID、用例版本 UUID、**当前**用例名称、当前版本清理步骤的顺序/启停/方法/条件/提取数量/轮询次数，以及关联该定时任务和精确用例版本的最近一次执行证据。名称经常见 URL、邮箱、长数字和凭据赋值遮盖，但自由文本可能仍包含未识别的敏感信息；查看和保存结果时须限制访问。没有匹配记录时历史为 `null`；trace 缺失为 `null`，空数组只说明记录中没有可识别的清理步骤，不证明清理成功。

trace 仅输出清理步骤序号、尝试次数、白名单状态/分类和输出有无；被脱敏或缺失时为未知。它不输出请求、响应、变量名/值、报错文本或步骤名称。`nonempty_recorded` 只表示脱敏记录中存在非空提取，并不证明是本次创建或业务归属正确；也不代表关联资产被清理。业务规则或名称中的特殊敏感内容仍需谨慎处理。

只读数据库账号设置 `API_TESTING_DATABASE_URL` 后执行：

```bash
python3 scripts/scheduled_cleanup_diagnostics.py /path/to/scheduled-report.json
```

事务为 `REPEATABLE READ READ ONLY`，每条语句限时 5 秒；仅 SELECT。只输出通用错误，非零退出不能当成盘点成功。结果不覆盖在途任务、未来计划修改，也不证明候选执行器上线安全。
