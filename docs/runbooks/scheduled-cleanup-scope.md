# 已启用定时任务清理结构盘点

该脚本只读分析已启用 API 定时任务的当前目标和递归依赖。`cases` 直接取用例版本；`baselines` 取活动基线的版本；`baseline_group` 取同项目同组的活动基线；`task` 取同项目、所选接口上的活动基线。依赖包含可选依赖。输出只含任务 UUID、用例版本 UUID 与清理结构布尔值。

**结果为权限未过滤的保守上界，不是实际可执行列表。** 当前实现不模拟执行人权限、运行时来源或环境校验，也不包含已经排队或运行的历史快照。即使列表为空，也不证明任务健康、数据归属或候选清理保护可以发布。识别空目标、缺失或跨项目对象、非法依赖、循环依赖和无法解析 UUID 时拒绝报告完整结果；结构无法判定时为 `indeterminate`。其他项目内非定时手动任务不在本次范围内。

在只读数据库账号所处环境中设置 `API_TESTING_DATABASE_URL`，安装现有 psycopg 3，并将本脚本与 `audit_cleanup_compatibility.py` 放在同一目录。脚本开启 `REPEATABLE READ READ ONLY` 事务及每语句 5 秒超时，仅执行 SELECT；不要把凭据写入命令、日志或聊天。输出可能包含内部任务标识，请限制文件读取权限。

```bash
python3 scripts/scheduled_cleanup_scope.py
```

任何异常只输出通用失败信息，非零退出表示范围未确认。具体任务仍需根据实际权限及运行时快照单独核对；脚本不执行接口，也不改变任务或资源。
