## 正确性与边界

- 私有 SQLite 保存当前文档及不可变修订，owner/app 权限在服务端重新读取。AI 后台最多一个生成任务、无自动重试队列；模型建议不能自己确认步骤，不能派发手机。
- 生成优先参考当前应用下最多三条成功基线；支持实际缓存结构，不能用同模块下其他应用样例替代。
- 文字编译只使用现有白名单，显式预期生成实际 aiAssert；与相邻完全相同的检查点复用，避免重复调用。最后仍需明确检查点。固定包名仅作为源应用，经现有编译器映射选中平台；iOS 不支持的输入/滚动明确拦截。
- 试跑复用原 UiExecutionStore/dispatch/claim/event 协议，冻结当前修订、源哈希及目标编译结果。精确设备、权限、能力、占用与停止检查保持原逻辑。
- 发布必须本人当前版本、真实通过且停止已确认，有完整原始任务步骤标签/总数/结束游标；不使用页面推导的绿勾当证据。仅发布到当前应用独占模块。文件原子落盘，元数据最后发布，崩溃重试不制造空占位文件、不覆盖其他文件。
- 创建、修改、恢复、校验、试跑和发布接入操作审计；试跑请求记录为已受理，不将 HTTP 成功等同执行通过。
