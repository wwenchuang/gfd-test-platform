## Apifox 契约与真实接口差异

CAD 首版暴露了三个必须按真实响应修正的问题：

1. 创建接口真实返回的 `data` 是整数任务 ID，不是文档假设的 `data.id` 对象。旧提取会在真实任务已创建后失败。
2. 改名接口实际限制任务名最多 10 个字，超限返回 HTTP 200、业务码 1002，不能按传输成功处理。
3. 任务处于 `PROCESSING` 时删除返回 HTTP 200、业务码 1001。v3 采用有上限的详情轮询，只有状态为 `SUCCESS` 且 OBJ、预览图存在后才改名和删除。

失败版本产生的两个调试任务均已精确删除。v3 每次运行还会用新名称查询列表，删除后要求该名称的列表总数为 0，因此没有把清理结果建立在删除按钮或 HTTP 200 上。
