# 功夫豆测试平台体验走查记录（2026-08-26）

## 范围与方法

- 线上页面：`http://101.34.197.12:8088/task-manager.html`
- 账号状态：用户已协助完成登录；使用新页面逐项进入 Agent、用例、执行、报告、配置入口。
- 检查维度：首次进入、列表扫描、筛选定位、详情查看、历史操作、配置入口、失败反馈、长列表性能和窄屏布局。
- 破坏性操作边界：走查允许创建临时数据；删除既有记录和真实发送飞书仍保留页面内二次确认，本轮未代用户确认发送外部消息。

## 现场证据

1. Agent 运行记录一次渲染 26 张完整卡片，页面 DOM 约 4583 个节点、367 个事件监听器；每张卡片包含结果、轨迹和操作，缺少搜索、状态筛选和分页。
2. Agent 工作台的原生模型下拉会在首屏加载完整模型目录，模型较多时既增加请求和 DOM，也不利于用户快速选择默认策略。
3. “应用配置”进入后直接弹窗，“执行环境”进入后自动触发 Sonic 全量扫描，“群通知”和“缺陷草稿”只有说明页；导航名称与实际页面职责不一致。
4. 执行报告最多一次渲染 200 行，失败任务工作台最多一次渲染 80 个任务；历史记录缺少组合筛选和分页。
5. 登录失败后再成功，旧错误 Toast 可能继续悬浮；新建模块、任务和上传文件的服务端失败被吞掉，页面仍本地添加并显示成功。
6. 主页面依赖 Google Fonts，内网或受限网络会让静态资源加载受到外部站点影响。

说明：浏览器自动化控制链本身的等待时间不计入产品加载性能；上面的 DOM、入口行为和渲染数量来自页面状态与代码路径交叉验证。

## 已实施

### 列表与历史操作

- Agent 运行记录增加任务/应用/结果搜索、结果状态筛选、Agent 模式筛选和每页 8 条分页。
- 执行报告增加任务/应用/报告搜索、执行状态、失败归因筛选和每页 15 条分页。
- 失败分析任务增加搜索和每页 12 条分页。
- 报告与失败分析按需读取最近 500 条 Runner 和 200 条生成任务；页面明确展示当前可搜索范围，服务端同时返回是否仍有更早记录，避免把前端分页误解为全量历史。
- 筛选栏保持稳定尺寸，小屏自动单列；长列表不再一次性创建全部详情 DOM。

### 工作台与性能

- 工作台首屏只加载自动策略和已配置的 AI Gateway Provider；完整模型目录改为用户点击“加载更多模型”后按需获取。
- 移除 Google Fonts 依赖，改用系统中文字体和系统等宽字体。
- 所有本轮修改的静态资源统一更新缓存版本，部署后无需依赖用户手工清缓存。

### 配置与导航

- 应用配置、群通知、执行环境改成独立状态页；编辑继续复用原应用配置弹窗。
- 进入执行环境不再自动扫描 Sonic，快速体检、深度体检和旧步骤扫描均为明确按钮动作。
- “设备连接”改为“执行环境”，“系统设置”改为“环境体检”。
- 运行记录、待确认、失败报告和待确认缺陷草稿增加侧栏计数；导航分组展开状态和最后管理页可恢复。

### 缺陷草稿闭环

- Agent 产品缺陷和失败分析生成的草稿会真实持久化，不再只存在当前浏览器或单次 run artifact。
- 新增缺陷草稿列表、状态/关键字筛选、复制、拒绝、来源执行 ID、报告链接和人工确认发送。
- 草稿发送时按应用包名解析对应 Webhook；发送成功、失败、拒绝均保留状态和操作信息。
- 草稿提交和拒绝只接受已验证管理员会话，Runner Token 无权触发外部发送；操作人由后端会话取得，不接受浏览器请求体伪造。
- 草稿写入和发送使用线程锁与进程文件锁，临时文件名唯一；同一草稿的并发提交只能发送一次。飞书 `code / StatusCode` 的数字和字符串成功码统一识别，避免消息已送达却仍显示失败并诱发重发。
- Agent 失败任务和模型轨迹随草稿保留。
- 真实发送前保留二次确认，不会因进入页面或生成草稿自动发群。

### 结果真实性

- 新建模块、任务和上传 YAML 的服务端错误不再被吞掉；失败时停止本地更新并显示具体错误。
- 登录成功会清理旧登录错误和 Toast，避免成功状态仍展示失败提示。

## 暂缓与原因

- 后端历史接口仍以有限条数返回，前端已控制 DOM 数量；真正的游标分页需要统一 Agent run、job 和报告存储协议后再做。
- 缺陷草稿当前沿用带跨进程文件锁的服务端 JSON 持久化，适合现有单机部署；多主机共享部署前应迁移到数据库并增加全局幂等键。
- 本轮未真实提交飞书卡片，也未删除线上既有运行记录；相关流程通过单元测试、静态检查和页面二次确认验证。
- 旧页面仍保留部分 emoji 导航图标和历史样式，未在本轮做全站视觉重构，以免扩大回归范围。
