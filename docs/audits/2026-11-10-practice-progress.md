# AI 测试平台改造进度与计划差距

核对时间：2026-11-10 10:55（北京时间）。本记录依据原 18 周手册、现有平台的已存证据和 `CODEX_STATE.md`；它是一次进度快照，不代表之后的线上状态。原手册的订单示例按用户要求替换为现有 App、后台和接口资产，不另建模拟订单业务。周次只用于内部对照，不作为同事使用平台的导航。

目前已推进到第四周的功能和验证，但第二、第三、第四周均不能认定整周通过；第一周也有用户暂缓的人工项目和需确认的盘点项。原计划中的数量和连续运行轮次是验收目标，不能用其他历史基线数量代替。

## 第一周：环境、模型与首条冒烟

- **已上线并有当时的真实证据：**网页上的千问文本与图片探针分别得到真实响应并保留历史；服务器端匿名反馈接口、登录页 UI 的正向与故意失败冒烟分别记录退出码 0 和 1，UI 截图与 trace 可供查看。已认证接口另有真实执行记录；这些不等于平台 Runner 已完成登录后业务 UI 验收。
- **待完成或暂缓：**10 条人工场景计时、视觉结果的人工核对和周验收按用户要求暂缓；用户初步判断千问为按量计费，账单类型尚未单独核实。平台盘点中未实证的 Runner、队列等仍应标为未验证。证据及限制见 `CODEX_STATE.md` 的“第 1 周网页执行链”“第 1 周五项缺口补充”和“第 1 周千问网页探针”。

## 第二周：测试工程与真实接口基础

- **已上线并有当时的真实证据：**真实反馈分类只读执行 `de803f8b-e18b-4e67-986d-b14ce737b8aa` 的 HTTP 状态、业务码和结构断言通过。工作台按授权读取既有执行后，原始三项断言和 17 项本地数据处理检查通过；分析本身未再次调用业务接口。这 17 项不是 17 次业务执行。
- **仍缺：**真实业务客户端的异常链、实际请求号与业务日志关联，以及写入响应丢失后的数据归属和可恢复清理，尚无充分现场证据；人工场景基线和审核暂缓。已有真实请求号记录及其限制见 `CODEX_STATE.md` 的“第 2 周真实业务实战”“第二周网页真实验收”和“第四周继续核验”。

- **已有阶段成果：**平台已提供真实接口资产、用例、执行记录和工作台入口；工作台和同事“开始测试”入口经过线上页面核验。开始测试仍用于同事选择应用、用例、手机和发版回归，不因改造而改成周次操作。

## 第四周：数据、清理与依赖异常

- **已上线并有当时的真实证据：**接口编辑器明确提示功能用例只使用第一条启用数据行；同 seed 的测试文本预览可复现，但尚不是与执行绑定的真实数据工厂。执行详情提供清理核对提示。生产环境中用户曾单独授权一次创作会话创建与按本次返回 ID 清理，执行 `0157b386-1475-4946-aae8-1664498ecc69` 的主体和清理步骤通过，后续查询不可见；这不证明物理数据或关联资源已清除。接口来源预览可展示部分定义差异，并标示比较不完整。
- **本次已验证、网页尚未部署：**只读检查既有反馈分类执行 `1eb0c640-d78a-41f9-b441-02785fd87e1c`，执行与接口来源版本和环境一致；脱敏历史响应包含当时根合同必填的 `code`、`msg`、`data`。使用平台断言器在内存中逐一去掉字段均未通过。合同含递归引用，该检查仅覆盖根级必填字段存在性，不能作为完整合同、线上实时响应或 Mock 契约通过的证明。对应的权限保护和工作台展示代码已合并推送、测试通过，仍待服务器部署和真实网页验收。
- **仍缺：**与真实执行身份绑定的数据工厂和可追溯 run ID、跨账号资源隔离、可替换真实依赖的六类异常、小规模幂等并发、完整合同与异常后的资源归属和清理证据。当前用户指定生产环境；此前一次创建和清理的授权只覆盖那一次，不代表可以重复写入或删除生产数据。详见 `docs/audits/2026-11-05-week4-real-platform.md` 和 `docs/audits/2026-11-09-session-ownership-capabilities.md`。
