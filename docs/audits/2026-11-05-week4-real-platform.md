# 第四周真实平台对照：测试数据与 Mock

更新时间：2026-11-05。第四周目标是在现有 App、后台和接口测试平台上建立可复现的数据、运行隔离、定向清理及外部依赖异常验证；不另造模拟业务系统，不将 Mock 结果计为真实集成结果。

## 已核实

- 原计划要求数据工厂、账号和资源隔离、六类外部依赖响应、实际支持的幂等与并发、契约漂移检查、数据 SOP；累计 40 条 API 是前序与本周合计目标。第三周用例及三轮执行尚未完成验收，不可继承为已通过。
- 服务器只读盘点接口平台环境名称：3D 家用项目当前启用的是生产环境，另有已归档环境；启用的隔离演示环境属于非业务演示项目，不能作为真实 App 验收环境。共享业务 QA 后台存在，但服务、数据及依赖是否隔离尚未证实。
- 现有功能用例的数据行仅使用排序后第一个启用行；依赖和前置处理可覆盖同名变量。用例编辑器已补充说明与动态状态，限定功能调试/回归并区分压测数据和基线版本。
- 线上通过校验的静态文件增量更新，无服务重启。使用现有反馈分类用例，仅在浏览器内临时新增两组并停用首组：显示首组停用、第二组保存后使用；之后移除两组，未保存、未发起调试或业务请求。新页面在宿主和静态容器的文件校验一致。
- 功能用例编辑器本地 39 项检查通过，前端静态检查 84 项通过；这一修正没有实现多组逐行执行。

## 待完成及依赖

- 基于真实接口约束建立可复现的数据生成能力，并验证同 seed 与运行标识；不同运行的隔离仅在真实字段允许写入唯一标识且数据归属可查证时可宣称成立。
- 确认真实业务非生产环境、测试账号、数据归属与清理路径，再验证两轮隔离、异常中断后的恢复、小规模并发与幂等契约。
- 核实现有真实业务外部依赖的可替换能力后，验证成功、400、500、超时、断连和坏 JSON，并保留真实服务契约验证；没有隔离条件时不得统计为真实业务集成验收。
- 第三周的需求映射和同版本三轮、第二周写入响应丢失后的可恢复清理仍未验收。人工审核/计时按用户要求暂缓。

## 测试文本预览上线验证

- 现有接口用例编辑器新增可重复文本预览：数字 seed 和 32 位数据编号生成固定模板文本，仅可由用户显式填入空字符串变量；不会自动保存、调用接口或覆盖已有值，常见敏感变量名称禁用。过滤不能识别所有敏感字段，使用前仍需核对真实字段约束。
- 线上基于已有反馈分类用例，以 seed 0 和固定编号生成预览；再次点击得到相同文本。生成新编号后得到另一预览。没有点击保存或调试，未创建业务数据。测试预览并未声明该接口接受此字符串。
- 数据编号不自动关联平台执行 ID；seed 当前只是文本模板参数，不能证明真实业务资源唯一、运行隔离、并发安全或清理成功。68 项相关组件/页面测试、TypeScript、生产构建和 84 项前端静态检查通过；服务器宿主与静态容器资源校验通过，未重启服务。

## 接口定义差异能力的本地验证

- 已在现有接口来源的候选预览中增加响应定义变化详情，列出状态码、字段、必填项和枚举声明的变化。结果用于帮助人工审查，不代表线上真实响应符合契约，也不自动激活候选版本或阻断任务；遇到暂不支持的引用、组合或其他约束时会标明比较不完整。
- 独立临时 PostgreSQL 环境中，来源服务与差异比较共 89 项测试通过；页面 15 项测试、TypeScript 和生产构建通过，后端静态 63 项及前端静态 84 项通过。本节仅记录本地验证，尚未完成服务器后端部署及真实页面验收。
