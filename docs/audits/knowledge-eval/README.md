# 第十四周知识问答评估

本次在同一台机器、同一份已授权的智小白 3D 语料上比较 BM25 关键词检索和本地段落概念向量检索（ESA、余弦相似度）。每个问题依次交给两种方法，按题交替先后顺序。直接调用与工作台相同的 Python 检索函数，记录每次调用耗时，覆盖读快照、分词、构建索引、排序和生成摘录。网页加载、网络往返和并发吞吐需要另行测量。

两种方法的四个失分题相同。H02 询问精选通用套件封面的裁切方式及卡片模型信息，两者都选到新增套件表单的封面规格。H03（全部套件分类和例子）、H04（已购详情的内容入口和购买文案）、H07（品类套件的关联对象）都有对应条款，两者均返回证据不足。该批样本未显示向量方法的质量提升。留出结果始终按原版本保存。

## 题集、语料和指标

- 在读取留出题结果前固定题集。调优 10 题（6 可回答、2 无答案、2 越权），留出 30 题（20、5、5）。语料仅来自服务端的 7 份资料、47 个段落，涵盖套件专区、打印取消、EP7 实时观看各自的需求和用例，以及旧手机版用例的失败记录。题目和答案键在单独的测试夹具目录。报告带有每份原文件和取用快照的 SHA-256、计分脚本和检索模块摘要，便于核对版本。
- 每个可回答题在运行前指定一个主证据段落及必要事实。Recall@5 按文档 ID 和段落 ID 精确匹配，拒答计零分。引用支持要求第一项就是主证据、其摘录能在冻结段落中找到，且答案包含该摘录和全部必要事实。给出同主题的其他依据可能失分，语义等价答案与其他可用依据待独立评审。
- 无答案的五题中，四题涉及现有主题中未收录的具体事实，一题与领域无关。正确拒答要求状态为 unknown、固定证据不足提示、引用为空。越权题分别用空应用范围和仅含另一应用的范围提问。泄漏检查覆盖回答、候选引用、可见文档与段落数量、响应中出现的受限文档 ID。测试直接传入已解析的应用范围，端点身份鉴别需在实际服务独立验证。
- 调优前 BM25 与 ESA 均命中 4/6 个可答题，T01、T02 被拒，两组拒答各 2/2。保留原有词项覆盖率 0.44，另允许覆盖率达到 0.25 且正文至少含两个 IDF ≥ 2.5 的匹配项。改动后调优集两路均为 6/6、2/2、2/2，再冻结参数执行留出集。调优前后逐题回执分别在 [初始回执](tuning-before.json) 和 [最终回执](tuning-report.json)。
- 人工独立标注为 **0/30**。人工可以用单独的[评审空表](human-review.csv)记录每种方法的结果，核对摘录是否回答问题、相关语义遗漏、其他可用来源、拒答适当性和对根因的判断。该表尚无签收记录或主观正确率。

## 复算

在仓库根目录运行。两个命令只读本地固定语料和题集，写入指定 JSON 文件。

```sh
python3 tools/practice_knowledge_eval.py --split tuning --output /tmp/knowledge-tuning.json
python3 tools/practice_knowledge_eval.py --split holdout --output /tmp/knowledge-holdout.json
```

[冻结留出回执](holdout-report.json) 保存每道题的主证据 ID、答案键、应用范围、两种方法的前五项、拒答、泄漏判定和实测时间。比较复算结果时核对输入摘要、文档/段落 ID 和计数；时钟和每次耗时随执行环境变化。

## 工作台发布与复验

打开「测试工作台 → 测试知识检索」。默认关键词，在这一批题上向量没有提高召回。QA 实测「EP7 打印中的实时画面怎样唤醒？」两种方法均返回 ep7-prd / p3-7；无关问题返回未知；「查看检索评估与人工审查」回读了 30 道题及指标。权限的三个 HTTP 状态（401、403、200）另在隔离环境用普通账号验证，勿把隔离环境的账号当作线上受限账号。

部署时代码与 task_server/knowledge_sources/ 一同发布，保证服务账号对语料父目录有遍历权限。把 holdout-report.json 安装到私有目录 requirement-design-materials/evaluation/knowledge-holdout.json，沿用工作台其他私有报告的属主和权限。语料不发往外部模型；当前答案是所引用原文的摘录，没有调用大模型改写。
