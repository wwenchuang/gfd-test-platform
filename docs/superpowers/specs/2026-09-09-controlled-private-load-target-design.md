# 受控内网压测目标设计

## 目标

允许用户在网页环境配置中，按服务显式授权访问企业内网压测目标，解决节点连通性已通过但平台单用户预检被公网地址策略拒绝的问题。

## 方案

- 在每个环境服务上保存 `metadata.allow_private_network`，默认缺省或 `false`。
- 环境编辑页在服务地址下展示“允许访问受控内网地址”复选框和风险说明；保存会创建新环境版本，历史执行仍引用原版本。
- HTTP 执行器只在当前请求选择的服务开启该标志时，允许 RFC1918 IPv4 或 IPv6 ULA 地址。
- 即使开启，也继续拒绝回环、链路本地、未指定、组播和保留地址；DNS 结果全部校验并固定到已校验 IP。
- 服务基础地址、Host 请求头和同源重定向规则保持不变，授权不会扩散到其他服务或其他环境版本。

## 验收

- 默认环境仍拒绝内网地址。
- 显式授权的服务可完成内网请求；同一环境中未授权服务仍被拒绝。
- `127.0.0.1` 和 `169.254.169.254` 在授权后仍被拒绝。
- 页面编辑、保存和再次打开时正确保留开关，并清楚显示风险说明。
- 后端专项、前端专项、静态检查、生产构建和 Safari 实际流程通过。
