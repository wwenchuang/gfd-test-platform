# 测试平台全流程体验修复设计

## 目标

本轮以线上真实点击为准，优先保证功能可完成，其次优化历史操作、页面响应、上下游衔接和新手可理解性。保留现有无框架前端、Runner、Sonic 与 Agent 协议，不做大规模重构。

## 现场问题

1. 登录和切换 Agent 页面会并发请求同一份运行记录；执行页会同时触发首次加载、立即轮询和定时轮询；模型配置也会重复读取 Provider 与路由。请求在服务端锁后排队，历史详情可超过前端 15 秒超时。
2. 单个 Agent 详情读取会先扫描并恢复全部历史记录，和列表请求争用同一把锁。
3. 执行中心的“失败重跑”只有分析、修复、定位，没有真正的重跑动作。
4. 新建 YAML 的默认内容固定真实设备 ID，且包含空的 `ai:`，新手创建后得到的不是可直接编辑、校验的中性模板。
5. Agent 历史只能逐条删除；历史页仍显示执行侧栏，主列表被压窄。详情请求失败时，页面没有说明已保留摘要。
6. 完整模型目录一次显示约 200 个原生选项，应用模块配置一次显示 100 多个复选框，缺少搜索。
7. 页面残留英文装饰标题、原始失败代码、纯数字步骤和含义不清的比例/单位；Trace 空状态误用“没有执行报告”。
8. “AI 修复”和“失败分析”页面职责接近但标题相同，用户难以判断下一步；应用配置没有突出未归属模块。
9. API 测试平台当前选中“生产环境（新）”，但调试、任务、基线、定时任务手动运行、历史重跑和步骤预览都能直接发送真实请求；步骤“预览”尤其容易让新手误以为只是本地查看。
10. API 测试各管理页仍使用大写英文装饰标题，环境栏没有持续提示生产风险，执行确认也没有说明目标环境、对象和用例数量。

## 方案

### 请求与历史

- 为 Agent 列表、Jobs、模型配置增加进行中 Promise 复用，完成后清空；同一数据在请求未结束时只允许一个网络调用。
- Agent 历史和待确认页自行读取 50 条，不再先读取 10 条。
- 单个 Agent 详情只读取持久化记录，不触发全量恢复扫描。列表接口继续负责有限范围的陈旧状态恢复。
- 详情超时时保留已显示摘要并给出明确提示。
- 历史页增加当前页选择、清空选择和批量删除；只允许删除终态记录，统一二次确认并汇总成功/失败。

### 功能闭环

- 失败重跑表格增加“确认重跑”按钮，复用现有 retry API，不改变服务端协议。
- 新建 YAML 使用 `android: {}` 和有明确可编辑提示的 `ai` / `aiAssert` 模板，不绑定设备。
- Trace 与快照使用独立空状态。
- AI 修复页按入口区分“失败分析”和“AI 修复”，并提供报告、修复、重跑、缺陷草稿的上下游动作。

### 新手与展示

- 完整模型目录加载后出现搜索框；应用模块弹窗支持搜索、已选/未归属计数。
- Agent 历史和待确认页隐藏无关执行侧栏，执行页保留任务状态区。
- 装饰标题、步骤编号、失败类型和数量单位改成中文可读形式；技术 ID 仍在详情和日志中保留。
- 应用配置展示“已归属 / 总数 / 未归属”并提供直接筛选未归属模块的入口。

### API 执行安全

- 环境栏在生产环境下持续显示“生产环境 · 执行前确认”，让用户在所有管理页都能看到当前风险，而不是只在下拉框内看到环境名称。
- 调试、任务执行、基线执行、定时任务手动执行、历史重跑和步骤预览统一经过执行确认；确认内容必须包含环境、操作对象、可用时的用例数量，并明确请求会真实发送。
- 确认发生在保存任务或准备执行之前；用户取消后不保存范围、不创建执行记录、不调用目标接口。
- 步骤预览继续展示请求和响应证据，但按真实执行管理，不再把它当成无副作用的静态预览。
- 管理页装饰标题改为中文；HTTP、JSON、Cron、Webhook 等通用技术名词保留，避免为了中文化损失准确性。

## 边界

- 不自动执行 Runner、安装 App、同步 Sonic、修改模型策略或发送飞书，这些真实外部动作继续由用户显式确认。
- 不删除既有线上历史；点检创建的临时 YAML 在验收后清理。
- API 测试平台本轮完成入口和九个导航页点检；不真实执行生产接口、不改环境、不修改定时任务。新增确认流程通过本地浏览器、组件测试和端到端测试验证。

## 验收

- 首次登录只有一次最近 Agent 请求；进入历史只有一次 50 条请求；进入执行只有一组 Jobs/修复草稿初始请求；进入模型配置只有一组 Provider/路由请求。
- Agent 详情不再因全量恢复锁等待而超时。
- 失败任务可在失败重跑页直接重跑；历史可批量选择和删除；模型与模块可搜索。
- 新建 YAML 不包含固定设备 ID 和空 action；页面不再显示指定英文装饰标题和原始失败代码。
- API 测试平台所有真实请求入口在执行前展示环境与对象；生产环境持续可见，取消确认不会保存或执行。
- 前后端静态检查、Python 编译、视觉回归和 `git diff --check` 通过。
