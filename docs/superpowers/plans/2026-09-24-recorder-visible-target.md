# 录制前景控件识别与启动步骤展示修复

**目标：** 修复弹窗按钮误用背景 XML 日期、首页展示原始资源 ID，以及自动启动详情混入每个点击详情。

**方案：** 点击前截图与点击位置共同交给视觉识别；XML 保留作诊断证据，不直接作为已确认语义。人工标记继续优先，失败阻止生成可调试 YAML。自动启动作为独立时间线项目。

**约束：** 不更改真实触摸发送，不重写历史证据，不删除业务打印记录；手机 PHM110/ecbfd645 与打印机 MAC 分开。用户部署后验收新版本。
