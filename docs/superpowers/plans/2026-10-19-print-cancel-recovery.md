# 打印取消受控恢复实施计划

依据已批准设计：`../specs/2026-10-19-print-cancel-recovery-design.md`。

1. 先写状态机测试：首次成功、暂时失败后成功、处理中不连点、退避中成功、次数/总时限、错误任务、停止与迟到响应。
2. 独立平台合同：确认打印并绑定本次新任务、取消本次任务两种语义操作，编译为现有官方aiQuery，由Mac Runner已验证适配层解释；普通CLI/旧Runner拒绝。禁止新YAML action/字段。
3. Mac安卓/iOS共享同一JS状态机；提交前验证打印机空闲，提交仅一次，捕获新任务唯一标识。身份不可见或状态不明确失败关闭。取消预算和每次动作均检查截止时间/任务代次/停止信号。
4. 草稿编辑与视频生成接入显式、可审查的打印恢复标记；原始点击与失败证据留存。结果记录尝试/耗时/恢复成功，不伪装首次成功。
5. 能力校验覆盖编译、派发复查、Runner启动前校验；窗口/缓存隔离、进程停止沿用既有合同。
6. 运行相关测试、AGENTS检查和独立代码审查，更新启动说明/状态。当前不进行物理打印验收，真实设备执行须具备现场条件；部署终端当前由用户操作。
