# 脑图文件检索与分组计划

用户要求：解决文件堆叠、无法搜索、缺少分类的问题。采用紧凑列表，不增加后台轮询；不改权限和报告接口；列表补充原始请求中保存的应用包名，新生成摘要持久化应用包名。

- [x] 搜索标题/模块/YAML文件/批次编号，多关键词且不区分大小写；筛选模块、可下载/待生成/已删除文件、只看已选。
- [x] 默认按应用→模块分组、组内更新时间倒序，可切换最新优先或标题排序；全部应用时每个应用先显示最近3条，每页4个应用；查看全部进入应用内，每页12条。无模块显示未分类；明确显示当前结果数和搜索范围。
- [x] 保留跨页选择，只选当前页，显示隐藏选择数；刷新数据清理已消失记录，搜索输入不丢失焦点；刷新与返回脑图中心保留筛选。
- [x] 紧凑行显示标题、状态、更新时间和用例数，下载/生成报告常驻，更多操作放分析、重建、删除，沿用原确认框与鉴权。
- [x] 前端从既有接口加载最多500条（服务端既有上限），达到上限明确提示；不声称全库搜索。不新增请求频率。当前56条全部可搜索。
- [x] Node回归涵盖组合筛选、分页、跨页选中/清空、刷新删除、中文输入焦点、空状态、转义和原操作入口；前后端静态、语法、diff。
- [x] Chrome本地实际组件宽/窄屏查看：用户允许独占后，实际点击应用展开、中文搜索及更多操作，核对390px容器内换行和菜单可见性；模拟数据，不替代上线真实数据验收。
