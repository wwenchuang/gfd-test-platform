# 每日基线条件恢复计划

**目标：** 修正成长报告与组件详情的数据依赖，并使固定测试设备的切片取消、创建与清理形成可复验闭环。

**设计：** 给功能用例的前置及清理步骤增加可选 `only_if_variable`。变量不存在或为 null、空字符串、空数组、空对象时记录中文原因并跳过；0 和 false 是有效值。未配置条件的历史步骤行为不变。条件仅决定是否发请求，不替代业务断言、设备身份或最终待机校验。前置试运行与完整执行采用同一判定。变量名接受严格格式及静态来源校验。复制到尚不支持条件的压测场景时拒绝，不能静默删除条件。

**方案取舍：** 单纯延长轮询不能清理切片；无条件取消在无任务时不成立；本次采用最小的有值条件，不引入表达式或脚本执行。

**约束：** 仅使用 9888E0094F2A。必须先确认当前任务属于指定设备，再取消并验证恢复；不得从“slicing”直接放宽到允许打印。保留业务码、身份和结构断言。保留 Word 与晋升材料。在 main 修改。
