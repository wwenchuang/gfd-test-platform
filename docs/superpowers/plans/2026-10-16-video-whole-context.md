# 完整录屏时轴识别与原视频验收

问题：6帧分批丢失上下文，导致重复确认、漏滚动；consolidate强制保留了错误候选。只读对照显示58帧逐图带frame_id+timestamp的事实观察能恢复完整导航和正确删除对象。native视频虽然能恢复导航但对象识别不稳定，不采用。

方案：完整时轴事实观察（ui_video_observe）→现有索引绑定执行规划（ui_video_steps consolidate）。每阶段最多60张/10MiB base64，超限失败不截断；时间由平台从真实frame_refs绑定，统一inferred。规划保留必要交互、Top3参考、动态对象门禁。常态2次调用，最多一次规划纠正。其他技能图片限制不变。所有草稿仍需核对和真机验证。
