# Windows 三组件启动计划与设计

目标：首次选择现有 Sonic Agent 和 Runner 启动脚本、FRP 程序及配置，以后双击启动和检查；无需复制密钥。

采用已有 Python 3.8+ 标准库实现与 CMD 入口，系统 PowerShell 仅查询进程和管理已有服务，不增加服务包装器依赖。相比仅串联三个 start 命令，增加配置预检、命名互斥锁、进程识别、已存在 Runner 服务复用、有限等待和独立日志。相比一次性安装三个系统服务，本版不改变用户身份、服务账户、启动权限或机器执行策略，避免破坏现有 Java/ADB/Node 环境。

Sonic 支持已有 JAR，Runner 支持已有 Python，二者兼容原 .bat/.cmd，使用其目录为工作目录；FRP 使用现有 exe 和 ini/toml/yaml 配置。所有路径先校验；无歧义才启动，疑似已有实例时不新增。启动窗口保留失败信息；FRP 输出单独写日志。状态明确区分进程存在与远控 TCP 可达，TCP 可达也不代表画面已验收。配置只保存路径，不保存或展示令牌。
