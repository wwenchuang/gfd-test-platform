# 独立压测演示服务交付计划

用户已同意用独立可控服务验收完整报告，不改FRP/真实AI。main实施，保留用户文档。

1. 部署包：Python标准库服务、Docker资源约束、Prometheus可选同机采集、明确无特权无Docker socket。只读自身cgroup v2，不伪造资源指标；无cgroup时metrics失败。
2. 固定接口：正常、延迟、HTTP500、业务失败、短CPU占用、共享有界内存TTL、采集暂缺。无任意脚本、URL转发、任意参数增长。管理故障独立令牌；并发和请求时限固定上限。
3. 默认loopback，不开放公网；需要真实互通内网或HTTPS网关才接平台。不修改防火墙/FRP。不消耗AI额度。
4. 测试真实HTTP认证、错误分离、并发资源上限、TTL、指标缺失、cgroup数值口径；Docker真实测量CPU/内存和Prometheus真实查询，平台现有查询构造交叉验证。
5. 提供中文部署/场景矩阵、回滚和网络安全说明，打tar.gz和sha256；提交推送main。无服务器访问或网络配置时明确部署及在线报告尚未完成。
