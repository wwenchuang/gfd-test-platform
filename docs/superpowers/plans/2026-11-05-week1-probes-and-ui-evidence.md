# 第 1 周模型探针与服务器 UI 证据实施计划

**目标：** 新手在平台网页发起固定的千问文本和图片检查，回看结果；服务器上对真实登录页完成无副作用的 UI 正向、故意失败和重跑演练。

**约束：** 保留既有用例、基线与定时任务；不使用真实设备或登录凭据；不接受网页提交自定义目标地址、模型、图片路径或提示词；密钥与原始错误不得出现在结果或日志。调用真实模型会产生费用。人工计时必须由真人完成，模型调用成功不能代替人工核对视觉答案，单项通过不能冒充整周验收。

1. 梳理现有 Task Server 配置与身份权限，提供固定文本和固定图片的真实模型调用及持久化记录；区分模型调用、结果核对和失败状态，限制并发并控制输出。用定向测试检查鉴权、参数约束、失败记录和敏感信息处理。
2. 在第 1 周引导中提供清楚的探针入口、费用提示、进度、可理解的错误和历史记录；刷新页面后检查记录可读，视觉结果保留人工核对状态。
3. 在服务器上的独立目录执行只访问真实登录页的自动化：空用户名校验通过；反向断言故意失败并保存截图、日志；从新进程重跑并保存证据。不得把该演练描述成已登录的业务流程或设备 Runner 验证。
4. 整合运行结果、剩余人工计时与局限到第 1 周阶段记录，更新 `CODEX_STATE.md`；执行相关专项测试、前后端静态检查和 `git diff --check`。确认线上版本及工作负载后部署，在真实网页验证调用及刷新后结果。
