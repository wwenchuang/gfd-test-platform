# 测试平台实战流程易用性：第一批

目标：让使用者按第 1 周步骤进入现有流程，找到创建入口，理解 API 编辑和调试的影响；复用现有权限、校验与执行证据。

范围：
- 在开始测试页提供创建用例入口，转到用例库现有素材选择器；尊重编辑权限、离页保护与账号切换。
- 增加可折叠的第 1 周指南，链接已有功能并说明网页尚未提供探针、人工计时和周验收。
- API 编辑器明确当前版本和保存影响；提示原用例保存及调试会创建新版本和更新任务范围，提供现有独立创建入口；独立复制需解决幂等后再做。
- 沿真实服务端流程核对页面、权限和执行结果；不把脚本生成、探针或历史运行当成实际业务通过。
- 补第1周已有服务器/模型/API结果，UI正反证据与真实人工基线分开记录；人工计时由真人操作，不能填造。

验证：先以行为测试复现入口缺失和副本身份问题，再跑前端专项、API 定向测试与构建、前后端静态检查和 diff 校验；部署前对照线上资源与当前版本，部署后实测并记录结果。已有生产数据、用户改动、设备约束与原定时任务全部保留。
